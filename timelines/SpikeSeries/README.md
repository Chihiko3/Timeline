# Spike Series 时间线

本目录保存 Spike Series 工作室创作谱系的独立数据与资源。

## 收录边界

- 收录 Chunsoft、Spike、Spike Chunsoft 主导开发或建立原创品牌的关键商业游戏。
- 保留《勇者斗恶龙》开发期、Sound Novel、不思议迷宫、Fire Pro、侍道、喧哗番长、弹丸论破、极限脱出、AI 与超侦探事件簿等创作线。
- 仅代理发行或本地化、普通移植与合集、大量授权改编不单独列卡。
- 未来作品必须确认到具体全球最早正式发售日期后才进入时间线。

## 文件

- `releases.js`：一级卡片、日期与平台记录。
- `editorial-reading.js`：核心体验、本作变化和研究线索，并保存该时间线共用的编辑研究底稿。
- `design-logic.js`：机制底层逻辑。
- `series-impact.js`：对工作室后续创作的具体影响。
- `external-impact-research.js`：仅展示有可核对依据的行业影响。
- `plot-summaries.js`：剧情概要与叙事创新。
- `milestones.js`：国内与全球化里程碑。
- `timeline-images.js`：GM 图片管理清单。
- `assets/covers/`：时间线本地图片。
