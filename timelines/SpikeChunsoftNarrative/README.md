# Spike Chunsoft Narrative 时间线

本目录保存 Spike 与 Chunsoft 相关叙事游戏的设计谱系。目录名 `SpikeChunsoftNarrative` 与当前时间线显示名称一致；时间线改名时，目录、页面脚本、GM 图片路径和资源清单必须同步改名。

## 收录边界

- 以 Chunsoft 开发的 1985 年《港口镇连续杀人事件》FC 版作为指令式推理前史；该卡片不把堀井雄二 1983 年 PC 原作归入 Chunsoft，也不将其标为 Sound Novel。
- 从 Chunsoft 1992 年《弟切草》建立的 Sound Novel 主干出发，并明确它对传统“唯一答案、错误即阻塞”冒险结构的改造。
- 收录《恐怖惊魂夜》对可求解推理的改造，以及《街》《428》对真人群像、并行时间表和跨角色因果的推进。
- 收录《极限脱出》把多周目知识与密室解谜结合的分支。
- 将旧 Spike 独立形成的《弹丸论破》标为并行分支；2012 年 Spike 与 Chunsoft 合并不等于两条设计线此前存在直接继承。
- 收录合并后或与核心创作者明确相关、且继续推进推理与交互叙事的《AI：梦境档案》《超侦探事件簿》《终天教团》。
- 《勇者斗恶龙》《风来的西林》《侍道》《喧哗番长》《Fire Pro》等仅因公司相同、但不属于该叙事设计链的作品不再列入。
- 普通移植、合集和不改变设计结构的复刻并入平台记录；日期采用全球最早正式发售日。

## 文件

- `releases.js`：一级卡片、日期、平台记录与谱系关系。
- `editorial-reading.js`：核心体验、本作变化、机制逻辑、系列影响、剧情概要与叙事创新的研究底稿。
- `design-logic.js`：从研究底稿生成机制底层逻辑。
- `series-impact.js`：从研究底稿生成对后续叙事作品的具体影响。
- `external-impact-research.js`：仅展示有可核对依据的行业影响。
- `plot-summaries.js`：从研究底稿生成剧情概要与叙事创新。
- `milestones.js`：本地确立、全球传播与组织整合节点。
- `timeline-images.js`：GM 图片管理清单。
- `assets/covers/`：时间线本地图片。
