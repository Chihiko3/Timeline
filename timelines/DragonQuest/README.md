# Dragon Quest timeline

This directory owns the Dragon Quest series timeline.

- `releases.js`: earliest release dates, branches and platform history
- `editorial-reading.js`: core loop, changes and research prompts
- `design-logic.js`: system-level design interpretation
- `series-impact.js`: concrete influence inside the series
- `external-impact-research.js`: externally sourced industry impact
- `plot-summaries.js`: plot summaries and narrative innovations
- `selection-criteria.js`: visible inclusion policy
- `timeline-images.js`: GM-managed image manifest
- `assets/covers/`: repository-owned timeline artwork

Ordinary ports stay in `later`. A remake or definitive edition receives its own primary card only when it substantially rebuilds presentation, scenario flow or systems.
