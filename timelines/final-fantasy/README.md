# Final Fantasy Timeline

This folder owns all Final Fantasy timeline content:

- `final-fantasy-releases.js`: release chronology and platform history
- `final-fantasy-covers.js` and `final-fantasy-logos.js`: imported artwork maps
- `timeline-images.js`: GM-managed card artwork records
- `assets/covers`: cover and logo files used by the timeline

Shared timeline layout and card styling are in `../../common`.
